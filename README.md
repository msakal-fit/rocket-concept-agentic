# Rocket Concept Agentic

Experimental multi-agent engineering project.

Goal:
Explore whether a role-separated Codex workflow can develop,
integrate, and independently validate a small launch-vehicle
concept simulation.

This repository is primarily an experiment in agentic engineering
workflow, not a flight-ready launch-vehicle design.

Development proceeds through explicit fidelity levels:

- Level 0 — end-to-end software sanity
- Level 1 — simplified mission simulation
- Level 2 — improved engineering fidelity
